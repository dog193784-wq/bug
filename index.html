GitHub Pages Takeover Triage

A static, read-only helper for reviewing a hostname that may point to GitHub Pages. It queries Cloudflare's public DNS-over-HTTPS endpoint for CNAME evidence and lets you record independent HTTP observations. It does not attempt to claim a repository, add a custom domain, or change DNS.

1. Inspect a hostname

Use only a hostname you own or are explicitly authorized to assess. Enter a hostname, not a URL.

A CNAME to *.github.io, an absent CNAME, an HTTP 404, or a generic error is not proof of takeover. This page reports indicators only and cannot determine whether a site is claimable.

2. Validation checklist

Treat every result as a lead until the evidence supports a conclusion.

  • Confirm the hostname is explicitly in the bug bounty program's scope.
  • Review the DNS CNAME response and relevant resolution errors; DNS-over-HTTPS answers can be cached or incomplete.
  • Correlate the target with current GitHub Pages documentation and the exact HTTP response.
  • Do not attempt to attach the target domain to a repository or publish content on a third-party domain. For claimability testing, use a domain you control and follow GitHub's rules.
  • Record evidence, timestamps, and false-positive checks. Report as “potential” unless claimability is established in an authorized lab.
